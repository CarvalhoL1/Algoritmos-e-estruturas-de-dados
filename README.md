# Algoritmos e Estruturas de Dados

Repositório contendo implementações de algoritmos e estruturas de dados desenvolvidas durante a disciplina de **Algoritmos e Estruturas de Dados** da graduação em Ciência da Computação.

O objetivo deste repositório é servir como material de estudo, consulta e prática dos principais conceitos vistos em aula.

---

## Tecnologias

- Java
- Python
- C

---

## Conteúdo abordado

- Complexidade de algoritmos
- Recursão
- Estruturas lineares
- Árvores
- Grafos
- Algoritmos de ordenação
